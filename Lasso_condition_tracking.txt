# Event-Driven Divide and Conquer for Lasso Post-Selection Inference

## 1. Context

We compute the post-selection p-value of a selected Lasso coefficient by
enumerating, on the test-statistic line `z`, all the *over-conditioning intervals*
`{ z : the Lasso active set / signs stay constant }`. A p-value is then read off
a truncated-normal pivot restricted to the intervals that match the observed
active set `M_obs` (see `sfs_da_package/pivot.py`).

### 1.1 Original approach: restart-and-solve

`divide_and_conquer_Lasso_nonDA` walks `z` from `zmin` to `zmax` by:

1. solving the Lasso at a restart point `z`  →  obtains `(M, sM)`;
2. computing the interval where `(M, sM)` is the Lasso solution, i.e. solving
   the linear inequalities `A z <= B` built from the KKT conditions
   (`conditioning_Zv_Lasso_nonDA`);
3. restarting at `R + 1e-4`, where `R` is the interval's upper bound.

**Weaknesses**

- The Lasso is re-solved with coordinate descent at **every** interval. Near an
  event, solver tolerance decides whether a coefficient is exactly `0`, so the
  active set can be returned inconsistently.
- The `+1e-4` restart offset is arbitrary; it is only a numerical crutch.
- Nothing structural carries information from one interval to the next.

## 2. Key observation: adjacent intervals are connected by "events"

Each interval is the feasibility polyhedron of the Lasso KKT conditions for a
fixed `(M, sM)`:

```
interval = { z : A z <= B },   A = f(X, a, b),   B = g(X, a, b, Lambda, M, sM)
```

Because the Lasso solution path is continuous and piecewise-linear in `z`, the
interval boundaries of two consecutive intervals are **exactly equal**, and the
boundary is produced by some inequality becoming tight. Which inequality becomes
tight *is* the information that determines the active set of the next interval.

The rows of the inequality system have a known ordering (see
`conditioning_Zv_Lasso_nonDA`):

| row range | meaning | tight at the *upper* bound ⇒ |
|-----------|---------|-------------------------------|
| `[0, |M|)` | active feature `i`: sign condition `sM_i * beta_i(z) >= 0` | `beta_i = 0` → **feature `i` leaves**, signs of the rest unchanged |
| `[|M|, |M|+|Mc|)` | inactive feature `j`: `u_j(z) <= +Lambda` | `u_j = +Lambda` → **feature `j` enters with sign `+1`** |
| `[|M|+|Mc|, |M|+2|Mc|)` | inactive feature `j`: `u_j(z) >= -Lambda` | `u_j = -Lambda` → **feature `j` enters with sign `-1`** |

where `u_j(z) = X_j^T( Y_z - X beta(z) )` is the KKT subgradient of an inactive
variable. These update rules follow directly from stationarity and complementary
slackness.

This is exactly the well-known Lasso **homotopy / LARS** idea, applied here to
the SFS conditioning structure.

## 3. The event-driven (path) algorithm

`divide_and_conquer_Lasso_nonDA_path`:

```
solve Lasso once at z = zmin            # (M, sM)

while current start z <= zmax:
    1. compute interval [L, R] AND the upper-bound event rows   (conditioning_Zv_Lasso_nonDA_with_events)
    2. append [L, R] and (M, sM)
    3. if R >= zmax: break
    4. derive (M', sM') from the upper event rows               (_advance_active_set)
    5. compute the predicted next interval for (M', sM')
    6. accept the step if the predicted interval restarts exactly at R
       (continuity check: |L' - R| <= tol and R' > R + tol)
         - on success: (M, sM) <- (M', sM'), continue  → NO Lasso solve
         - on failure: fall back to restart-and-solve at R + 1e-4
```

The only Lasso solve is the very first one. The remaining intervals are pure
linear algebra on fixed `(X, a, b, Lambda)`.

### 3.1 Updating the active set (`_advance_active_set`)

For each upper-bound event row `r`:

```
r < |M|                     →  remove feature M[r]
|M| <= r < |M| + |Mc|       →  add feature Mc[r - |M|]  with sign +1
else                        →  add feature Mc[r - |M| - |Mc|] with sign -1
```

Multiple events at the same boundary (degenerate simultaneous hits) are applied
together: all leavers are removed and all joiners are added in one step.

## 4. Correctness

- **Theory**: if the Lasso solution is unique (generic `X`, columns in general
  position), the path `z ↦ beta(z)` is continuous and piecewise-linear, the
  active set `(M, sM)` is constant on each open segment, and the segments tile
  the line. Hence an interval's upper bound is exactly the next interval's lower
  bound, so the continuity check is necessary and, at non-degenerate events,
  sufficient.
- **Empirically** (see `test.py`, `np.random.seed(0)`): the event-driven walk
  reproduces the restart-and-solve interval lists **exactly**:

| interval | restart | path |
|----------|---------|------|
| 1 | `(-inf, -3.516253]`  M=[0,2,4] | same |
| 2 | `[-3.516253, -0.465859]` M=[0,4] | same |
| 3 | `[-0.465859, 0.120826]` M=[4] | same |
| 4 | `[0.120826, 0.545490]` M=[] | same |
| 5 | `[0.545490, 1.667516]` M=[0] | same |
| 6 | `[1.667516, inf)` M=[0,2] | same |

  Lasso solver calls: **6** (restart) vs **1** (path). p-value `0.007719748800542048` matches.

  The walk also traverses the *empty active set* interval (`M = []`) correctly,
  which restart-and-solve also produces.

## 5. Robustness and fallback

The method is intentionally conservative:

- **Degenerate events** (several inequalities tight at the same boundary, or an
  event at a point where the path changes in a non-generic way) are detected by
  the continuity check `|L' - R| <= tol` / `R' > R + tol`, and the code falls
  back to the original restart-and-solve step. This makes the path method
  `>=` the restart method in robustness.
- Near-zero `A_i` rows (numerically ~0 slopes) are skipped, as before.
- An empty active set is supported: `sM` is kept as a `(0,1)` array and the
  conditioning algebra (`np.linalg.inv` of a `0 x 0` Gram matrix) is valid.


def divide_and_conquer_Lasso_nonDA_path(X, a, b, n, Lambda, zmin, zmax, verbose=False):
    # Event-driven (homotopy / LARS-style) variant of divide and conquer.
    #
    # The Lasso is solved only once, at zmin. From there, every new interval is
    # inferred from the inequality that is tight at the upper bound of the current
    # interval:
    #   * an *active* row hits z where that coefficient -> 0   -> feature leaves
    #   * an *inactive* row (u <= +L) hits +Lambda              -> feature enters (+1)
    #   * an *inactive* row (u >= -L) hits -Lambda              -> feature enters (-1)
    # Inference is accepted only if the predicted next interval restarts exactly
    # at the previous upper bound (continuity). Otherwise we fall back to the
    # original restart-and-solve step, which also covers degenerate events
    # (several inequalities tight at the same point).
    list_intervals = []
    list_M = []
    eps = 1e-7
    tol = 1e-7
    n_solver_calls = 0
    n_inferred = 0
    n_fallbacks = 0

    z = zmin
    Y_z = a + b * z
    M_v, Mc_v, sM_v = util.solve_Lasso(X, Y_z, Lambda)
    n_solver_calls += 1
    
    interval_v, lower_events, upper_events = conditioning.conditioning_Zv_Lasso_nonDA_with_events(
        X, a, b, Lambda, M_v, Mc_v, sM_v, verbose=verbose)

    while z <= zmax:
        # print(z)
        if verbose:
            print('=' * 70)
            print(f'[event-driven interval #{len(list_intervals) + 1}],  start z = {z:.6f}')
            print(f'  M = {M_v.tolist()},  sM = {sM_v.ravel().tolist()},  Mc = {Mc_v.tolist()}')

        R = interval_v[0][1]

        if verbose:
            print(f'  -> interval_v = [{interval_v[0][0]:.6f}, {interval_v[0][1]:.6f}],  '
                  f'lower event rows = {lower_events},  upper event rows = {upper_events}')

        list_intervals += interval_v
        list_M += [M_v]

        if R >= zmax:
            break

        M_next, sM_next, ok = _advance_active_set(M_v, Mc_v, sM_v, upper_events)

        step_ok = False
        if ok:
            Mc_next = np.setdiff1d(np.arange(X.shape[1]), M_next)
            interval_next, lower_events_next, upper_events_next = conditioning.conditioning_Zv_Lasso_nonDA_with_events(
                X, a, b, Lambda, M_next, Mc_next, sM_next, verbose=False)
            L_next = interval_next[0][0]
            R_next = interval_next[0][1]

            if np.isfinite(L_next) and abs(L_next - R) <= tol and R_next > R+tol:
                step_ok = True
            else:
                print(np.isfinite(L_next))
                print(abs(L_next - R) <= tol)
                print(R_next > R+tol)

        if step_ok:
            n_inferred += 1
            if verbose:
                print(f'  [infer OK] -> next M = {M_next.tolist()}, sM = {sM_next.ravel().tolist()},  '
                      f'predicted next L = {L_next:.6f} equals R = {R:.6f}')
            M_v, Mc_v, sM_v = M_next, Mc_next, sM_next
            interval_v = interval_next
            lower_events = lower_events_next
            upper_events = upper_events_next
            z = interval_v[0][0]
        else:
            n_fallbacks += 1
            print('sos')
            if verbose:
                print(f'  [fallback] inference rejected (degenerate / numerical); solve Lasso at z = {R + eps:.6f}')
            # z = R + eps
            # Y_z = a + b * z
            # M_v, Mc_v, sM_v = util.solve_Lasso(X, Y_z, Lambda)
            # n_solver_calls += 1
            # interval_v, lower_events, upper_events = conditioning.conditioning_Zv_Lasso_nonDA_with_events(
            #     X, a, b, Lambda, M_v, Mc_v, sM_v, verbose=verbose)

    if verbose:
        print('=' * 70)
        print(f'[summary] intervals = {len(list_intervals)},  lasso solver calls = {n_solver_calls},  '
              f'inferred steps = {n_inferred},  fallbacks = {n_fallbacks}')

    return list_intervals, list_M



def conditioning_Zv_Lasso_nonDA_with_events(Xtilde, a, b, Lambda, M, Mc, sM, verbose=False):
    A, B, _ = _construct_Zv_Lasso_nonDA(Xtilde, a, b, Lambda, M, Mc, sM)

    if verbose:
        _print_Zv_inequality_set(A, B, A.shape[0] - 2 * Mc.shape[0], Mc.shape[0])

def _construct_Zv_Lasso_nonDA(Xtilde, a, b, Lambda, M, Mc, sM):
    # Builds A, B so that the over-conditioning interval of (M, sM) is {z : A z <= B}.
    XtildeM = Xtilde[:, M]
    XtildeMc = Xtilde[:, Mc]

    XtildeMT_XtildeM_inv = np.linalg.inv(XtildeM.T.dot(XtildeM))
    XtildeM_plus = XtildeMT_XtildeM_inv.dot(XtildeM.T)
    XtildeMT_plus = XtildeM.dot(XtildeMT_XtildeM_inv)

    # Construct Atilde0 and Btilde0
    Atilde0 = - sM * (XtildeM_plus) 
    Btilde0 = - Lambda * sM * (XtildeMT_XtildeM_inv.dot(sM))

    # Construct Atilde1 and Btilde1
    Atilde10 = XtildeMc.T.dot(np.identity(Xtilde.shape[0]) - XtildeM.dot(XtildeM_plus))
    Atilde11 = - Atilde10

    tmp = XtildeMc.T.dot(XtildeMT_plus).dot(sM)
    Btilde10 = np.ones((tmp.shape[0], 1)) - tmp
    Btilde11 = np.ones((tmp.shape[0], 1)) + tmp

    Atilde1 = np.vstack((Atilde10, Atilde11)) / Lambda
    Btilde1 = np.vstack((Btilde10, Btilde11))

    Atilde = np.vstack((Atilde0, Atilde1))
    Btilde = np.vstack((Btilde0, Btilde1))

    A = Atilde.dot(b)
    B = Btilde - Atilde.dot(a)
    return A, B, Atilde.shape[0]


def _advance_active_set(M, Mc, sM, upper_events):
    k = len(M)
    nin = len(Mc)

    M_set = set(M)
    s_dict = {f: float(sM[i, 0]) for i, f in enumerate(M)}

    for r in upper_events:
        if r < k:
            f = M[r]
            M_set.discard(f)
            s_dict.pop(f, None)

        elif r < k + nin:
            f = Mc[r - k]
            if f in M_set:
                return None, None, False
            M_set.add(f)
            s_dict[f] = 1.0

        else:
            f = Mc[r - k - nin]
            if f in M_set:
                return None, None, False
            M_set.add(f)
            s_dict[f] = -1.0

    M_next = np.array(sorted(M_set), dtype=int)
    sM_next = np.array([s_dict[f] for f in M_next], dtype=float).reshape(-1, 1)

    return M_next, sM_next, True
